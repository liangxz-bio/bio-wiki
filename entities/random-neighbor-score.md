# RNS — 蛋白质 embedding 的样本级不确定性度量

Prabakaran R, Bromberg Y. *Quantifying uncertainty in protein representations across models and tasks*. Nature Methods (2026) 23:796-804. doi: 10.1038/s41592-026-03028-7. PMID: 41922570.

Case Western Reserve University（Bromberg 实验室）。提出 **Random Neighbor Score（RNS）**——观察一个蛋白 embedding 周围有多少"随机序列邻居"，用来给表示质量做预检。

## 核心问题：embedding 没有置信度

蛋白质语言模型输出的 embedding 常被直接当作序列的"数字身份证"——找相似蛋白、预测结构、判断突变、训练新分类器。可与结构预测不同，这张身份证**通常没有置信度**。

**最危险的情况**：向量看起来正常，实际位置却和随机打乱的无生物意义序列混在一起，下游模型仍会一本正经地给出答案。

## RNS 定义

把真实蛋白和随机对照（保持氨基酸组成、随机打乱顺序的假序列）共同嵌入同一空间，对目标蛋白寻找最近的 k 个邻居，再计算其中随机序列的比例。

- 若 1000 个近邻里有 120 个来自随机集，RNS = 0.12
- 若一个都没有，RNS = 0
- **不需要重新训练模型**，也不依赖某个特定下游解码器
- 可用于 ESM、ProtT5 或其他任意能输出 embedding 的模型
- 常用 k=1,000，100 次欠采样求平均

## 关键结果

### Astral40 数据集（14,711 个结构域 + 73,555 条随机对照）

- RNS 与实验结构 TM-score 最高达 **Pearson 相关 −0.70**
- 不如 ESM 自身 pLDDT 与 TM-score 的 0.84 相关高，但 RNS 优势是**模型无关**
- 高 RNS 蛋白的整体接触预测精度下降约 **40%**
- 长程接触（序列间隔至少 24 位）下降**超过 60%**
- ProtT5 二级结构预测也随 RNS 升高而变差

### 人类蛋白组结果（18,100 条，长度 ≤ 1,022）

以 **RNS>0** 为阈值，各模型的不确定比例：

| 模型 | 不确定比例（RNS>0） |
|------|---------------------|
| ProtT5 | **19.1%** |
| ESM-2 3B | **46.2%** |
| ESM-1v | **27.5%** |
| ESM-2 650M | **15.2%** |

**3B 版本不是略差，而是比 650M 版本高出 31 个百分点。**

当阈值放宽到 RNS>0.1 时，四个模型的不确定比例分别降到 9.7%、10.4%、16.1% 和 8.8%。**因此标题中的"3B不如650M"只适用于这套人类蛋白、蛋白级 RNS 和指定阈值，不能泛化为总体能力排名。**

作者解释：这可能反映 3B 模型为结构相关目标形成了更专门的表示，却牺牲了部分序列层面的普适性。

### 突变效应实验

| RNS 范围 | 功能/致病变异分类 AUROC |
|----------|------------------------|
| RNS ≈ 0 | > 0.8（三种模型均表现良好） |
| RNS 升高 | 性能持续下降 |
| RNS > 0.8 | 接近 0.5（几乎无法区分有影响突变与中性突变） |

### 计算成本

10,000 条蛋白、k=1,000、100 次欠采样的设置下，RNS 计算约需 **2 分钟 GPU 或 14 分钟 CPU**。

## "junkyard" 概念

真实蛋白与随机对照重叠的潜空间区域——作者称为 **"junkyard"（垃圾场）**。

> 这不是说低质量蛋白本身没有生物意义，而是说当前模型没有把它放到一个能稳定反映生物关系的位置。

## 边界

1. **RNS>0 是极敏感阈值**：k=1,000 时只要出现一条随机序列就被计入不确定集合，46.2% 不能写成"46.2% 的人类蛋白 embedding 错误"
2. **依赖多个超参数**：随机对照集合、真实锚点集合、邻居数 k、距离度量、embedding 池化方式
3. **内在无序区、孤儿蛋白和低同源序列天然更难学习**：简单剔除高 RNS 样本可能系统性排除最值得研究的蛋白
4. **未覆盖所有任务**：论文验证了接触、二级结构和突变分类，不代表已覆盖蛋白功能、生成设计或复合物任务

## 实践含义

把模型选择从全局排行榜拉回到每条蛋白：
- **对低 RNS 样本**：可继续使用快速的 embedding 分类器
- **对高 RNS 样本**：触发更保守路线——补充 MSA、结构信息、相似家族证据，或直接标记为需要实验验证

RNS 把"不确定性"从模型级评价变成**样本级路由信号**——同一模型可以对不同蛋白采用不同的证据强度。
